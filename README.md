# Smart Budget Manager

## Description
Smart Budget Manager is a fully functional Command Line Interface (CLI) application that allows users to track their expenses securely. 
The application categorizes expenses, ensures correct data entry via Regular Expressions, and saves user data locally to a `.json` file using context managers.
It includes an advanced Analytics and Forecasting module that calculates categorical percentages, finds your most expensive habits, and projects future monthly spending based on the daily average.

## Run Instructions
1. Ensure you have Python 3 installed on your machine.
2. Open your terminal or command prompt.
3. Navigate to the project directory containing the files.
4. Run the script by typing the following command: 
   `python main.py`
5. Use the numerical keys to navigate the interactive menu and manage your budget.
